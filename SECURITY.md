# Security Policy

## Scope
This policy covers original CHEEKU INFINITY code, catalogue metadata, tests and documentation. Third-party projects have their own maintainers and security policies; report their vulnerabilities upstream.

## Reporting
Do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting feature for this repository when enabled, or contact the maintainer through the GitHub profile.

Include the affected version or commit, impact, reproduction steps and a suggested mitigation. Do not include real credentials or private user data.

## Safe operation
The CHEEKU INFINITY clone command fetches selected public repositories using Git. It does not execute downloaded install scripts. Review third-party code before running it.
