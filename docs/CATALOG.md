# Project Catalogue

CHEEKU INFINITY curates 16 independent upstream repositories.

## AI and machine learning

- [OpenVINO](https://github.com/openvinotoolkit/openvino) — AI inference optimization and deployment toolkit.

## Software engineering and coding agents
- [Superpowers](https://github.com/obra/superpowers) — agent skills for planning, testing, debugging and code review.
- [CLI-Anything](https://github.com/HKUDS/CLI-Anything) — tooling for agent-controllable command-line workflows.

- [Last30Days Skill](https://github.com/mvanhorn/last30days-skill) — agent workflow for recent trend and discussion research.
